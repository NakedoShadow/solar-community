# Identité visuelle

- `social-preview.png` — bannière GitHub (2560×1280). À uploader manuellement dans Settings → General → Social preview (GitHub n'expose pas cette action via l'API).
- `icon.png` — logomark seul (760×760, fond sombre plein), recadré depuis l'export du canvas. Servira au favicon du dashboard (`dashboard/`) une fois le code écrit.
- `lockup.png` — icône + wordmark horizontal (2560×1440), pour usage externe (site, doc, présentation).

Même famille visuelle que [BioSentinel](https://github.com/NakedoShadow/biosentinel/blob/master/docs/brand/README.md) (bouclier-gardien, fond quasi noir, Space Grotesk + IBM Plex Mono), palette ambre/or au lieu de cyan/vert pour différencier.

Source éditable (icône, lockup, bannière, sur un seul canvas) : demander la réouverture du canvas de design Solar Community si des retouches sont nécessaires.
